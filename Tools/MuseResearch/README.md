# MuseResearch (isolated, non-production)
The AWL-authored fixture driver and test controller compile/read the public upstream Muse SDK at exactly `1b894f551e64416e2844452ec6056ec56d6a10f1` in a temporary CI checkout. No upstream files or binaries are vendored into AWL. See [audit](../../docs/research/muse-noise-core-audit-2026-11-25.md) and [workflow](../../.github/workflows/muse-research.yml) for pinned source, commands, host dependency versions logged at runtime and timeout. This is a host-only experiment: no sockets or radio, actual device, account, credential, product or deployment. No third-party dependency added to AWL runtime. Upstream code remains under its own notices and terms; the host package installation does not approve redistribution.

The fixture uses the upstream C++ initiator/PSA backend and Python test responder over process pipes, generated ephemeral keys and synthetic payload. The direct test requires real success (no skip for missing host libraries); host suite skips, if any, must be reported separately. It also compares ordered reassembly across a chunk boundary, negative inputs, documented policy differences and local capacity/expiry semantics. Only categorical assertion results are emitted; no actual device data, keys or ciphertext in logs. Do not repurpose for connecting to a vendor service or product.

Run status and test observations belong in the research register and issue #641. Passing this experiment does not establish BLE/Wi-Fi provisioning, cloud authorization, real ESP32 firmware reachability, service-envelope interoperability, production security or fuzz coverage. All production adoption remains excluded.
