## Dependency and adoption decision (#639)

[Root README](https://github.com/facebookincubator/muse-gadget-sdk/blob/1b894f551e64416e2844452ec6056ec56d6a10f1/README.md#L42-L88) requires SDK token for pairing and points to separate service terms; its root Apache-2.0 license has explicit third-party exceptions. [Linux pyproject](https://github.com/facebookincubator/muse-gadget-sdk/blob/1b894f551e64416e2844452ec6056ec56d6a10f1/linux/pyproject.toml) declares Apache-2.0, cryptography>=3.3.2, websockets>=13 and optional sounddevice; [requirements lock](https://github.com/facebookincubator/muse-gadget-sdk/blob/1b894f551e64416e2844452ec6056ec56d6a10f1/linux/src/musegadget/data/requirements.lock) pins only websocket distributions with 326 hashes; distro cryptography/dbus/gi and optional PortAudio require independent provenance. Actual CI installed different newer dependency versions, so a successful CI run is not proof of a hash-locked production installation. Per-file Apache headers on reviewed Linux files do not clear external services or model/media rights. README separately identifies CC0 minimp3, Apache H.264 decoder, BSD-3-Clause libvpx with patent notice, OFL fonts and other attribution; Jollybot avatar excluded from Apache. No complete transitive SBOM, legal approval or security scan performed.

**KEEP AWL independence**: no Muse token/VM/backend, Noise stack, privileged systemd daemon, general-purpose shell/file APIs, or unreviewed binary/model. Reference only bounded frame/queue, identity/correlation, failure classification, selected target grant, typed consented actions and voice lineage. Existing issues #633/#634/#635/#637/#638 own independent PoCs/tests. #639 stays open for exact candidate reuse and dependency/license evidence; no copying approved.
