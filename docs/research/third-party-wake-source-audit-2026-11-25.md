## Hey James / KWS selection (#653)

- [Developer journal, March 21](https://crookse.com/journal/2026-03-21-ray-ban-meta-development-day-03): author reports host-side Porcupine detection after conversion to mono 16 kHz Int16 with 512-sample frames and a repeat-trigger rearm problem. Not a reproducible code checkout or verified input-route capture. Complete source and independent measurements not established.
- [Porcupine iOS quick start](https://picovoice.ai/docs/quick-start/porcupine-ios/) and [model API](https://picovoice.ai/docs/model-api/porcupine/) document on-device inference, platform-specific custom keywords, English and Korean models and required AccessKey/account. No account/key/model created, no licensing/redistribution approval or offline runtime behavior independently verified. Review exact terms before adoption.
- [openWakeWord pinned README](https://github.com/dscripka/openWakeWord/blob/368c03716d1e92591906a84949bc477f3a834455/README.md) documents English support, Apache-2.0 code and CC BY-NC-SA 4.0 bundled models. Do not infer Korean or commercial rights from code license. Apple Speech phrase matching remains the dependency-minimal host baseline; locale and on-device support need runtime checks.

Decision: defer adding KWS dependencies until #655 selects a host-side route from #656/#658. A future comparison must use the same consented positive/negative corpus, eligible models/rights, measure false accepts/hour, false rejects, latency, CPU, frame gaps, rearm and interruptions; separately test actual HFP duty cycle, battery, music and locked state. No model/sample imported. Explicit deferral, not a completed benchmark.
